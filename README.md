### 📌 Featured Projects

#### 🤖 [GridVAD — Open-Set Video Anomaly Detection](https://arxiv.org/abs/2603.25467)
Training-free pipeline using Vision-Language Models for zero-shot video anomaly detection. Achieves **77.59 Pixel-AUROC** on UCSD Ped2 — best among all compared methods. Combines a propose–ground–propagate architecture (VLM proposals → Grounding DINO → SAM2 mask propagation).
`Python` `PyTorch` `VLMs` `SAM2` · [📄 arXiv](https://arxiv.org/abs/2603.25467) · [🌐 Project Page](https://gridvad.github.io)

#### 🦾 [LLM-Based Robotic Task Planner](https://github.com/A7mdos/llm-robotics-task-planner)
Graduation project (Grade A+). An affordance-guided framework integrating LLMs with low-level robotic control — interprets scene semantics, selects action primitives, and executes on a Franka Emika Panda arm in Webots simulation. Bridges symbolic reasoning and continuous action through a modular perception–reasoning–execution architecture.
`Python` `LLMs` `Webots` `Robotics`

#### 📱 [Coach Fakkah](https://github.com/Gasimhacker/Coach_fakka)
A fitness-coaching mobile app built with Flutter. Coaches add clients, assign workout tasks, and track their progress, while clients update tasks to log their development — streamlining the whole coaching workflow in one place.
`Flutter` `Dart` `Mobile`

#### 🐚 [simple_shell](https://github.com/Gasimhacker/simple_shell)
A UNIX command-line interpreter written in C · *ALX project.* Replicates core shell behaviour — command parsing and execution, PATH resolution, built-ins, environment handling, and error management — built from scratch using low-level system calls.
`C` `Linux` `Systems Programming`
